# claude-cockpit

Claude Mods（Claude Code のプラグイン／関数フック）で、Claude と快適に作業するための環境を作るリポジトリです。
入力欄の上の帯、ペイン、トースト、ステータスなどを小さな Mod として足していきます。

## 方針

- セッションに紐づく情報は、セッションの中に置く
- 人と Claude が同じ Markdown ファイルを読み書きする
- 常に見える帯には「件数・状態」だけを出し、詳細はペインへ
- UI の制約はボタン（コピー・開く）と slash コマンドで補う

## Mod 一覧

| Mod | 内容 | 状態 |
| --- | --- | --- |
| コックピット帯 | 入力欄の上にモデル、コンテキスト使用率、費用、経過時間、ブランチを 1 行で表示。使用率が高いと色を変え、compact ボタンを出す | 予定 |
| ターン完了通知 | 長いターンが終わったらトーストと音で知らせる（短いターンは鳴らさない） | 予定 |

ほかの案（ツール実行タイムライン、作業ジャーナル、「あとで頼む」キュー、プロンプト・スニペット、ガードレールなど）は順次追加します。

## 構成（予定）

```
mods/
  cockpit-band/   # コックピット帯
  turn-notify/    # ターン完了通知
```
